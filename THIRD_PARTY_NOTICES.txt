The font/classic.json and font/mctiers.json registrations are adapted from
upstream font/gamemodes/classic-tags.json and mctiers-tags.json: resource
paths are namespaced to this mod.
The original 7-pixel height/ascent and F000-F007 glyph assignments are kept.

nethop maps to Classic neth_pot.png or MCTiers neth_op.png.
All imported artwork is obtained from the Tiers resource pack at the above
revision under that project's license, not extracted from Tier Tagger.
No Tiers Java code or PvPTiers icon set is included.

Tier color palettes
The HT1-LT5 MCTiers and PvPTiers RGB values are taken from the same Tiers
revision's resourcepacks/tiers-resources/assets/minecraft/colors/mctiers.json
and pvptiers.json (under src/main/resources/). Unmodified upstream files
are included as docs/mctiers-colors-upstream.json and
docs/pvptiers-colors-upstream.json for verification under the same GPL terms.
The MCTiers values were also checked against Tier Tagger's defaultColors:
https://github.com/mctiers-dev/TierTagger/blob/6f49034c9f800f1da330efa90e5810b2c0430d5c/common/src/main/java/net/uku3lig/tiertagger/config/TierTaggerConfig.java
No Tier Tagger Java code is copied. Retired #8FB6DC is the user's custom
choice and intentionally overrides each upstream palette's retired color.
